## Notes

- No INTERNET permission in manifest; network capture not applicable.
- App declares QUERY_ALL_PACKAGES - plausibly needed to enumerate apps inside managed spaces; worth confirming with author.
- Shizuku (moe.shizuku.privileged.api) installed but not running on the test device; Advanced tools/space-management flows not exercised.
- Core "create space" flow untestable on this device: app reports "Another profile exists and Android does not currently allow another work profile".
- Main screen, Refresh, and Advanced screens verified; no crashes or ANRs observed.
- App states no accounts, analytics, advertising, or network access; consistent with manifest (no INTERNET).
- VirusTotal: 0 malicious / 0 suspicious / 66 undetected.
