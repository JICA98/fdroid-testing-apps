## Notes

- Review on OnePlus 13 (API 36). Full flow verified: photo picker, editor with brush painting (strokes applied), Brush size, Undo/Reset/Erase, Start over, Save and Share (system share sheet opened). Save writes to /sdcard/Pictures/Unmark/unmark_*.png.
- Privacy claims verified at file level: the app displays a banner when the opened photo contains EXIF ("Found in this photo: 2 EXIF tag(s) (camera/software/location info) - All of this is dropped automatically when you save. Unmark never copies the original file, it re-encodes a fresh image from pixels only"). The saved output was pulled and audited: PNG chunk analysis shows ONLY image chunks (IHDR, sRGB, sBIT, IDAT x352, IEND) - no eXIf, no tEXt/zTXt/iTXt, no tIME, no iCCP, no gAMA/cHRM/pHYs, and a strings sweep found no GPS/make/model/software/date strings. Metadata removal claim CONFIRMED; the output is a fresh pixels-only re-encode (PNG, not a copy of the source JPG).
- Zero permissions declared (no runtime permissions, no storage permission - saves via app directory/MediaStore, no INTERNET, no MANAGE_EXTERNAL_STORAGE). Everything is offline; network section N/A.
- Custom adaptive icon (custom ic_launcher_background/foreground, monochrome layer). GPL-3.0-or-later; category Graphics per metadata; English UI.
- Note: metadata CurrentVersion is 0.4.0 (versionCode 7) while the MR pipeline builds 0.2.2 (versionCode 4) - the 0.4.0 build entry exists but the tested APK is the head build; fine, just noting.
- VirusTotal: 0 malicious / 0 suspicious / 67 undetected.
