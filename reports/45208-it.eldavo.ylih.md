## Notes

- Full review pass on OnePlus 13 (API 36): 3-step onboarding (welcome, bluetooth access, battery-optimisation exemption - all optional and clearly explained, skippable), automatic headphone detection from Bluetooth history (realme Buds Air 5 Pro and CPH2649 picked up instantly), LIVE session tracking verified (ongoing session grew from 22s to over a minute in real time on the pair detail screen), pair detail (lifetime hours, session count, average/longest, today/7d/30d, 14-day daily-hours chart), stats tab (all-headphones totals), settings (detailed tracking toggle, count-only-playback, per-device ignore checkboxes, export/import, battery troubleshooting link). JSON export via the SAF document picker produced a valid ylih-backup.json (devices/pairs/sessions with timestamps). No crashes.
- No INTERNET permission in the manifest (app states "there is no account, and the app has no internet permission") - network capture not applicable.
- Runtime permissions: BLUETOOTH_CONNECT is requested once during onboarding with a clear explanation that it is required for headphone tracking but skippable (rest of app still works, grantable later from settings) - acceptable for the app's core function. POST_NOTIFICATIONS is declared but was not requested at any point during testing.
- No MANAGE_EXTERNAL_STORAGE; data export uses the system SAF picker. All data is local (no account, no network).
- Custom adaptive icon with custom background/foreground and monochrome layer. MIT license; categories Multimedia + Time Tracker per metadata; English UI.
- VirusTotal: 0 malicious / 0 suspicious / 67 undetected.
