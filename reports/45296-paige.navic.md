## Notes

- Full review pass on OnePlus 13 (API 36) against the public Navidrome demo server (https://demo.navidrome.org, demo/demo): first-launch warning screen, server login, library home (random/starred albums, playlists), album page + track list, audio streaming playback (AudioTrack confirmed), next/pause/play via media keys, media-session notification with transport actions, foreground playback service, library tabs (Artists). No crashes.
- All traffic captured with PCAPdroid (app-filtered). Only two destinations: the configured music server demo.navidrome.org (Cloudflare) for API/streaming/cover art - core function; and api.github.com (GitHub API) = automatic update check against the project's GitHub releases, fired at app launch (3s after capture start, before login). No tracking, no analytics, no telemetry endpoints.
- The automatic update check against the GitHub API at launch is a concern: F-Droid itself provides updates, and the app should not self-update or direct users to sideload releases (violates the spirit of the Inclusion Policy; update prompts should be suppressed on F-Droid builds, e.g. via an F-Droid flavor/build flag). Flagged for the author.
- No runtime (dangerous) permissions requested; permission set is minimal and appropriate for a media player (INTERNET, WAKE_LOCK, RECEIVE_BOOT_COMPLETED, FOREGROUND_SERVICE_MEDIA_PLAYBACK, MODIFY_AUDIO_SETTINGS, ACCESS_LOCAL_NETWORK).
- GPL-3.0, categories Internet/Online Media Player/Radio per metadata; works with any Navidrome/Subsonic server (the "Log into your Navidrome instance" flow, custom server headers supported). No MANAGE_EXTERNAL_STORAGE.
- Custom adaptive launcher icon with monochrome layer. English UI.
- VirusTotal: 0 malicious / 0 suspicious / 67 undetected.
